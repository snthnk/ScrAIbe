# Откуда взята база аргументов

`arguments.csv` — 164 записи. Колонка `source` показывает происхождение каждой:

| `source` | Записей | Что это |
|---|---|---|
| `manual` | 74 | Стартовая база: пересказы составлены вручную по сюжетам произведений |
| `web_discovery` | 88 | Произведения и эпизоды найдены в открытых подборках аргументов для ЕГЭ; пересказ написан заново, короткими формулировками |
| `web_discovery:wikipedia` | 1 | «Люцерн» Л.Н. Толстого — сверка по Википедии (подтверждена лишь общая канва) |
| `web_verified:nukadeti.ru` | 1 | «Юшка» А.П. Платонова — сюжет сверен со страницей произведения на nukadeti.ru |

## Как собиралась

Из окружения, где работал автор, нет прямого доступа в интернет, поэтому автоматического парсера сайтов нет:
подборки читались через веб-поиск, а затем записи писались вручную. Тексты с сайтов **не копировались**.
Использовались открытые школьные подборки «аргументы для сочинения ЕГЭ» (ukogo.ru, 4ege.ru, ctege.info, rustutors.ru,
literaguru.ru, mel.fm и им подобные) — как список произведений и тем, но не как источник формулировок.

## Что нужно знать

* В агрегаторах такого рода встречаются фактические ошибки (перепутанные имена, выдуманные эпизоды), поэтому в базу
  попадали только эпизоды, в которых автор уверен по самим текстам; сомнительные (например, «Разбуженный соловьями» Селюжёнка) пропущены.
* Сверка по источникам для каждой записи по отдельности **не проводилась**: колонка `source` честно говорит, откуда взято
  произведение, а не кто подтвердил каждую деталь. Перед использованием в учебной работе факты стоит проверить по тексту.
* Теги — из словаря `agent_module/rag/tags.py`, по 3–5 на запись; ставились вручную.
* Формат расширения: добавьте строку в CSV (уникальный `id`, `source` любой) — индекс пересоберётся при следующем запуске.
